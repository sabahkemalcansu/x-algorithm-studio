# Golden summary rubric (concepts that must appear)

A good 10-bullet summary includes most of:

1. Personalization from **engagement history**  
2. **Retrieval** narrows a large corpus  
3. **Ranking** scores a smaller set  
4. **Multiple actions**, not one score  
5. **Positive** vs **negative** terms  
6. Public **mini Phoenix / sports demo** context  
7. **Not** live X production  
8. Filters as **hard rules** (if full system mentioned)  
9. Diversity / author repeat as later stage (optional)  
10. Studio purpose: run · understand · extend  

Red flags (auto-fail teaching quality):

- “Just sort by likes”  
- “This is exactly production X”  
- Guaranteed virality recipes
