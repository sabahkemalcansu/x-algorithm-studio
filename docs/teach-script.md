# Teach script — tone for human explanations

## Opening (10 seconds)

“For You is not a global popularity contest. It’s a **prediction** of what *you* will do next, built from what you did before.”

## Body (90 seconds)

1. **History** — likes, dwells, replies…  
2. **Retrieve** — pull candidates that look like a fit.  
3. **Score** — many probabilities, not one.  
4. **Combine** — positives up, negatives down.  
5. **Show** — top of the list.

## Concrete contrast

Always pair:

- one **high** item (high dwell/like, low block)  
- one **low** item (weak fit or higher block)

## Close

“So when something always lands on your feed, the system is betting you’ll engage — and not reject it. Public demo teaches that shape; live X adds more systems on top.”

## Languages

Prefer the user’s language. TR aha report is first-class; EN for global README.
