# Glossary

| Term | Meaning |
|------|---------|
| **For You** | Personalized home feed surface on X |
| **Thunder** | In-network candidate store (followed accounts) |
| **Phoenix** | Grok-based retrieval + ranking models |
| **Retrieval** | Narrow millions → hundreds of candidates |
| **Ranking** | Score/order a candidate set |
| **OON** | Out-of-network (not from accounts you follow) |
| **Dwell** | Spending time viewing content |
| **Multi-action** | Many P(action) heads, not one relevance score |
| **Candidate isolation** | Candidates don’t attend to each other in ranker |
| **Home Mixer** | Orchestration layer for the feed request |
| **Fixture mode** | Offline sample JSON for teaching without artifacts |
