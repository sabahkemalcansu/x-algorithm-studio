# Teaching weight packs

Used by `extensions/scorers/reweight.py` and ExplainScorer defaults.

| Pack | Story |
|------|--------|
| `teaching_default.json` | Balanced demo weights |
| `anti_negative.json` | Heavily penalize block/mute/report |
| `engagement_max.json` | Emphasize positive actions; softer negatives |

**Not production weights.** For literacy and A/B of *ranking logic shape* only.
